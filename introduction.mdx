## Overview
Storyfed is an end-to-end video generation API. Submit a prompt and optional parameters to receive a fully formatted, ready-to-post video with character consistency and captions.

## How Authentication Works
To use the API or the Make.com Custom App, you must secure an API Key from our portal.

Simply login or create an account, head to profile > API Keys > Create Key

## No-Code Integrations
* **Make.com:** You can use our official Make.com app to visually drag and drop prompts into the Storyfed video generator.
* **Webhooks:** Our API natively supports webhooks. Simply pass a `webhook_url` in your POST request, and we will push the final MP4 URL to you when rendering is complete.
